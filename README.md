# Project Selene · 日常负熵

> Becoming the woman I want to see in the mirror.
> 成为镜子里的自己也会喜欢的人。

一款适合 iPhone 使用的单页自我提升记录 App。围绕「自然女性化形象提升」设计的长期自我监督系统：不追求快速减肥，而是持续改善身材体态、化妆能力、护肤习惯、穿搭审美与自信风格。

## 页面结构

- **Today 今日** — 每日 8 项核心任务（完成 5 项即算成功）、心情记录、今日照片、一句话复盘、付款记录、低能量模式
- **Progress 进步** — 日历热力图（30/90天/全部）、数据统计、分类进步趋势、照片时间轴与前后对比
- **Body 身材** — 身体数据记录与趋势图、仪态练习（带计时器）、每周身体目标（最多 3 个）
- **Beauty 美妆** — 化妆分步练习与熟练度、本周练习重点、素颜/妆后相册、标准妆容卡、护肤流程、发型记录
- **Style 穿搭** — 风格关键词、我的颜色、今日穿搭、标准搭配、衣橱记录
- **Review 复盘** — 每周数据卡、复盘问题、规则式系统总结、下周计划、最近 30 天历史总结 + AI 深度分析
- **Profile 我的** — 身份宣言、最终目标、原则、最小行动、财务汇总、负熵指南、数据导出/导入

## 数据

- 数据保存在浏览器 `localStorage`，并自动同步到 Supabase（多设备合并，以较新记录为准）
- 照片压缩后上传到 Supabase 私密存储桶（云端不可用时降级为本地 Base64）
- 支持导出/导入 JSON 备份，清空数据需二次确认
- 兼容旧版「日常负熵」的全部历史数据（任务打卡、复盘、付款、妆容相册）

## 使用

直接打开 `index.html` 即可运行。建议在 iPhone Safari 中添加到主屏幕使用。
